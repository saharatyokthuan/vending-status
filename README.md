# 🏪 Vending Manager — ระบบจัดการตู้จำหน่ายสินค้าอัตโนมัติ

เว็บเพจสำหรับดูสถานะตู้จำหน่ายสินค้าอัตโนมัติ สรุปเหรียญและสินค้าที่ต้องเติม และจัดการรายการสินค้าหลัก ทำงานบนเบราว์เซอร์ล้วน (HTML + CSS + JavaScript) เก็บข้อมูลในเครื่องผ่าน `localStorage`

---

## ✨ ฟีเจอร์หลัก

| ส่วน | ความสามารถ |
|:---|:---|
| 🖥 **ภาพรวมตู้** | แสดง Machine Activation Code, กรอกและบันทึก จังหวัด / อำเภอ / GM / ย่านแบ |
| 💓 **สถานะเครื่อง** | ออนไลน์, สต๊อก, สแกนเนอร์, อุณหภูมิ, ธนบัตร, ลิฟท์ส่งสินค้า, ประตู, ประตูสินค้า และเหรียญ 1/5/10 บาท พร้อมไฮไลต์สีตามผลประเมิน |
| 📋 **นำเข้าข้อมูลตู้จาก CMS** | วางข้อความสถานะที่คัดลอกจากระบบ CMS หรือนำเข้าไฟล์ `.txt` แล้วระบบอ่านรหัสเครื่อง สถานะ เหรียญ และช่องสินค้าแต่ละชั้นให้อัตโนมัติ |
| 🪙 **สรุปเหรียญที่ต้องเติม** | คำนวณจำนวนที่ต้องเติมเทียบความจุ (1 บาท = 100, 5 บาท = 100, 10 บาท = 60 เหรียญ) พร้อมแถบความคืบหน้า |
| 🛒 **สรุปสินค้าที่ต้องเติม** | สรุปจำนวนช่องทั้งหมด / ช่องที่ต้องเติม / ช่องที่ไม่ต้องเติม / จำนวนชิ้นรวม (ช่องละสูงสุด 4 ชิ้น) และตารางรายช่อง |
| 🗂 **แผนผังตู้** | แสดงช่องแยกตามชั้น สีตามระดับสต๊อก (เต็ม, เหลือ 2-3, เหลือ 1, หมด/ติดลบ) และ tooltip รายละเอียด (ราคา, DropTest, สถานะช่องขาย, Rank, m, GP) |
| 📦 **รายการสินค้าหลัก** | ตารางสินค้า 12 คอลัมน์ ค้นหาจากชื่อสินค้า (ไทย/EN) หรือ Barcode กรองตามหมวดหมู่และสถานะ (`publish` / `disable`) |
| 📥📤 **นำเข้า / ส่งออกสินค้า** | นำเข้า `.xlsx`, `.csv`, `.json` และส่งออกเป็น `product.xlsx`, `product_<วันที่>.csv`, `product_<วันที่>.json` |
| 🏷 **แมปหมวดหมู่ (PMA)** | นำเข้าข้อมูล PMA / No. / Name (วางข้อความหรือไฟล์ `.txt`) เพื่อแปลงรหัสหมวดหมู่เป็นชื่อ |
| 🔔 **ใช้งานสะดวก** | แถบแจ้งเตือน, หน้าต่างยืนยันก่อนแทนที่ข้อมูลเดิม, แสดงเวลาอัปเดตข้อมูลล่าสุดที่ footer |

### ที่เก็บข้อมูล

ข้อมูลทั้งหมด (สินค้า, PMA, ข้อมูลเครื่อง, สถานะ, เหรียญ, ช่องสินค้า, เวลาอัปเดต) ถูกบันทึกใน `localStorage` ของเบราว์เซอร์ด้วยคีย์ `vendingManagementSystem.v1` ไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์ ข้อมูลจึงอยู่เฉพาะในเบราว์เซอร์และเครื่องที่ใช้งาน

## 🚀 วิธีใช้งาน

### เปิดใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที — หรือรันผ่าน local server:

```bash
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000

> ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ Font Awesome และไลบรารี SheetJS (ถ้าโหลด SheetJS ไม่สำเร็จ จะนำเข้า/ส่งออก `.xlsx` ไม่ได้ แต่ `.csv` / `.json` ยังใช้ได้)

### ขั้นตอนการใช้

1. นำเข้ารายการสินค้าหลักด้วยปุ่ม **นำเข้า** (`.xlsx` / `.csv` / `.json`) ที่ header — ไฟล์ `.xlsx` จะอ่านจากชีต `product` ถ้าไม่มีจะใช้ชีตแรก
2. คัดลอกข้อความสถานะตู้จากระบบ CMS มาวางในกล่อง "นำเข้าข้อมูลตู้" แล้วกด **อ่านข้อมูลจากข้อความ** (หรือกด **นำเข้าไฟล์ .txt**)
3. ดูสรุปเหรียญ สินค้า และแผนผังตู้ที่ต้องเติม
4. กรอกจังหวัด / อำเภอ / GM / ย่านแบ แล้วกด **บันทึกข้อมูลเครื่อง**
5. (ไม่บังคับ) นำเข้าข้อมูล PMA เพื่อแสดงชื่อหมวดหมู่แทนรหัส โดยวางข้อความที่บรรทัดแรกมีคำว่า `PMA` และ `Name` หรือนำเข้าไฟล์ `.txt` เมื่อเปิดผ่านเว็บเซิร์ฟเวอร์ ระบบจะลองโหลด `pma_product.txt` ที่อยู่โฟลเดอร์เดียวกันให้อัตโนมัติ (ไฟล์นี้ไม่ได้รวมอยู่ใน repo)
6. ใช้ช่องค้นหาและตัวกรองในตารางสินค้าหลัก หรือส่งออกข้อมูลสินค้าด้วยปุ่ม **ส่งออก**

## 🛠 เทคโนโลยีที่ใช้

- **HTML5 / CSS3 / JavaScript (Vanilla)** — ไม่มี framework และไม่มี build step
- **[SheetJS (xlsx) 0.18.5](https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js)** — อ่าน/เขียนไฟล์ Excel (โหลดจาก cdnjs)
- **[Font Awesome 6.4.0](https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css)** — ไอคอน (โหลดจาก cdnjs)
- **Google Fonts** — Inter และ Sarabun
- **Web Storage (`localStorage`)** — เก็บข้อมูลในเบราว์เซอร์
